# Danh mục Ảnh chụp Màn hình Hệ thống (Application Screenshots)

Thư mục này lưu trữ các hình ảnh minh chứng giao diện và luồng hoạt động thực tế của ứng dụng **Language Learning Web Application (v1.0.0 MVP)**:

1. `01-offline-review-session.png`: Giao diện phiên ôn tập thẻ Flashcard với thuật toán SRS v1 hoạt động khi ngắt kết nối mạng (Offline Mode).
2. `02-indexeddb-sync-queue.png`: Hàng đợi đồng bộ cục bộ (`syncQueue` trong IndexedDB) lưu trữ an toàn các thao tác ôn tập ngoại tuyến cùng thanh trạng thái `OfflineStatusBar`.
3. `03-pwa-offline-reload.png`: Ứng dụng PWA tải lại (Reload) hoàn chỉnh từ Service Worker App Shell khi đang mất mạng mà không mất dữ liệu học tập.
